**by [PhasedConnect](https://www.phasedconnect.eu)**

## English

Fortiqx Video Wall Controller is a simple Windows app for controlling video walls built with
Lightware VINX-110 decoders and VINX-120 encoders. Choose a layout (full video wall, wall + 2
screens, or separate screens), select a screen, and pick a source. No technical knowledge needed.

### Download

**[Download the latest version](https://github.com/PhasedConnect/FortiqxVW/releases/latest)**:
open the link and run `FortiqxVideoWallController-Setup-<version>.exe`.

Once installed, the app checks for new versions by itself and shows **Update available** when one
is published.

### Requirements

- Windows 10 or Windows 11 (64-bit)
- Network access to the VINX devices (TCP port 6107)
- Administrator rights to install or update

## Hrvatski

Fortiqx Video Wall Controller jednostavna je Windows aplikacija za upravljanje video zidovima
izgrađenima od Lightware VINX-110 dekodera i VINX-120 enkodera. Odaberite raspored (cijeli video
zid, zid + 2 zaslona ili zasebni zasloni), odaberite zaslon i izvor. Nije potrebno tehničko znanje.

### Preuzimanje

**[Preuzmite najnoviju verziju](https://github.com/PhasedConnect/FortiqxVW/releases/latest)**:
otvorite poveznicu i pokrenite `FortiqxVideoWallController-Setup-<verzija>.exe`.

Nakon instalacije aplikacija sama provjerava nove verzije i prikazuje **Dostupno ažuriranje** kada
je nova verzija objavljena.

### Zahtjevi

- Windows 10 ili Windows 11 (64-bitni)
- Mrežni pristup VINX uređajima (TCP port 6107)
- Administratorska prava za instalaciju ili ažuriranje
